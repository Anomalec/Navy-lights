# Огни · Navy Lights

Веб-приложение для изучения огней, дневных знаков и сигналов судов по МППСС–72. Все **144 иллюстрации и их подписи** извлечены из предоставленного PDF, без генерации новых схем. Оригинал сохранён в `sources/ogni-mppss72.pdf`.

## Запуск

Требуется Node.js 22 или новее и npm.

```sh
npm ci
npm run dev
```

Сервер разработки слушает порт 5173 на всех сетевых интерфейсах. Для публикации статического сайта:

```sh
npm run build
```

Разместите содержимое `dist/` на статическом хостинге с HTTPS. Приложение работает в корне домена и в подпапке, например `/Navy-lights/`. Загружайте всю папку, включая `assets` и `cards`. Серверная часть, аккаунт и ключи API не нужны.

Для открытия без установки и сервера используйте **`dist/ogni.html`**: это отдельный HTML-файл со всеми 144 картинками, шрифтами и кодом внутри. Его можно скачать и открыть браузером. Сохранение прогресса зависит от разрешений браузера на локальные файлы. Обычные `index.html` и `dist/index.html` предназначены для сервера, а не для открытия как файла.

Та же готовая версия с привычным именем **`index.html`** находится в **`dist/offline/`**. Открывайте именно этот файл, если запускаете приложение без сервера. Он содержит все картинки и код внутри; другие файлы ему не нужны.

## Ссылка для телефона — GitHub Pages

Готовый сайт для GitHub Pages находится в `docs/`: одна страница со всеми карточками внутри. Для публикации в настройках репозитория откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку **main** и папку **/docs**, затем **Save**. Это не требует изменения видимости репозитория.

После успешной публикации GitHub Pages выдаст адрес `https://anomalec.github.io/Navy-lights/`. До завершения публикации адрес не является подтверждённой рабочей ссылкой. В Safari или Chrome на телефоне сайт можно добавить на главный экран.

Если источником случайно выбрана папка `/(root)`, главная страница перенаправит на готовое приложение в `/Navy-lights/docs/`. При публикации из `/docs` приложение открывается сразу по основному адресу. Режим разработки и обычная production-сборка не перенаправляются.

Чтобы обновить опубликованный сайт после изменения карточек или интерфейса:

```sh
npm run prepare:pages
git add docs
git commit -m "Update GitHub Pages site"
git push origin main
```

Папка `docs/` обновляется отдельной командой публикации; обычная установка и `npm run build` её не меняют. Прогресс остаётся в браузере телефона и не передаётся на GitHub.

## Управление

- Нажатие на карточку или пробел: показать / скрыть исходную подпись.
- Свайп вправо, стрелка вправо или «Знаю»: отметить знакомую карточку.
- Свайп влево, стрелка влево или «Повторить»: добавить в список повторения.
- «Отменить действие» или Z: отменить последнюю оценку текущей сессии.
- Фильтры: девять тем, огни / дневные знаки, все карточки / повторение.
- Коллекция: поиск по подписям и запуск тренировки с выбранной карточки.

Прогресс и количество ответов за день сохраняются в localStorage этого браузера. Положение внутри сессии после перезагрузки начинается заново; отметки карточек сохраняются. В статистике можно сбросить прогресс с подтверждением. Дневная цель — 20 ответов, включая повторные попытки.

Production-версия кэширует приложение и все карточки через service worker после первой успешной загрузки. После завершения кэширования занятия доступны без сети. Service worker работает на HTTPS или loopback; в режиме разработки и в отдельном файле `ogni.html` он не регистрируется. При обновлении иллюстраций необходимо также изменить версию кэша в `public/sw.js`.

## Проверки

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Если Chromium уже установлен в системе, можно использовать его без загрузки браузера:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

Проверяются полнота данных, сохранение прогресса, повторение, отмена, переворот, свайпы, поиск, сброс и работа без сети. Браузерные проверки выполняются на десктопном и мобильном экранах.

## Повторное извлечение PDF

Изображения WebP и `src/cards.json` уже включены в проект; Python не нужен для запуска. Для повторного извлечения:

```sh
python -m venv /tmp/navy-pdf-venv
/tmp/navy-pdf-venv/bin/pip install PyMuPDF Pillow
/tmp/navy-pdf-venv/bin/python scripts/extract_cards.py sources/ogni-mppss72.pdf
```

Подписи, включая несколько возможных объяснений одной схемы, сохранены по источнику. Категория выбирается по первому упомянутому правилу; карточка без огней «Судно пришвартованное к берегу» относится к теме якоря и швартовки. Учебные карточки не заменяют актуальный текст правил.
